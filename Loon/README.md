# Loon 配置中心

这个目录用于存放个人 Loon 配置、插件清单和规则列表。

## 文件规划

- `Loon.conf`：主配置模板（不包含机场订阅链接、节点密码或证书私钥）。
- `Plugins.list`：插件清单与用途说明。
- `Rules/`：自定义分流规则。

## 使用说明

1. 在 Loon 中通过配置 URL 导入主配置，或按需单独添加插件。
2. 机场订阅地址、节点凭据、MITM 私钥等敏感信息不要提交到公开仓库。
3. 修改仓库文件后，Loon 端需要按对应配置/插件的更新入口手动更新；是否支持自动更新取决于导入方式。

当前目录先建立结构说明。等确认你的 Loon 版本、机场订阅导入方式和需要保留的插件后，再生成可直接导入的配置文件。

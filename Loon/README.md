# Loon 配置中心

用于集中维护 Loon 的分流、策略组和插件清单。

## 文件

- `Loon-template.lcf`：根据当前本机配置整理的脱敏模板。
- `Plugins.list`：插件清单说明。

## 机场订阅

本机当前使用三条订阅：
- `mesl`：WCloud
- `TAG`：保留
- `顺畅`：顺畅机场

**真实订阅 URL、token、节点密码和 MITM 私钥不进入公开仓库。** 模板的 `[Remote Proxy]` 区域只留了说明注释，不含真实订阅。不要直接用模板覆盖正在使用的配置；先在本机备份，再按需合并规则和策略组。

## 使用建议

1. 继续在 Loon 本机维护三条机场订阅及其自动更新。
2. 通过模板参考/更新策略组、远程规则和插件；订阅凭据只保留在本机。
3. 修改 GitHub 文件后，Loon 不会自动同步整份本地配置；需按 Loon 对应入口更新远程规则或插件，或手动合并配置。
4. 不要上传包含 `[MITM]` 的证书私钥、密码或完整原始配置。

## 当前基线

模板保留了原配置中的地区筛选、自动优选/故障转移、AI/Telegram/Google/媒体分流、广告规则和插件清单。具体策略是否可用，仍需在本机结合实际节点名称测试。
